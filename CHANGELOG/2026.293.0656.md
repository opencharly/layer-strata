# 2026.293.0656 — feat(strata): durable external-model/run-args surface + optional API key

## Summary

Adds the durable external-model/run-args surface, makes the **API key optional for a local deployment**, and corrects the stale mock-bed documentation — closing #9.

- **Optional API key** (`secret_accept` + `API_KEY_ARG`): the candy declared the key as `secret_require`, so `charly config` refused any keyless deploy; and the engine **rejects** an empty `--api-key` ("an API key was given but it is empty"). The candy now accepts an absent key, and the entrypoint emits `--api-key` **only when a key exists** (mock, setup and serve sites alike). A local pod therefore serves openly; setting the key still gates `/v1/*`.
- **Keyless gate assertion**: the plan's gate control is a declarative `http: 200` on `/v1/models`, matching what this bed deploys. (Its previous shell form read `$STRATA_API_KEY`, which an assert-only step does not export — measured DEAD — and a fixed `401` would red every keyless pod.)
- **Plan health probe**: `/health`'s `api_key` assertion moved from `is True` to `isinstance(..., bool)` — with an OPTIONAL key, "true" is no longer the only correct posture; the field must be present and boolean, and its VALUE is what the deployment supplied.
- **Mock branch de-duplicated**: the entrypoint's `STRATA_ENGINE=mock` branch wrapped an `exec` in an `if [ -n "$API_KEY" ]` whose both arms ran the SAME argv (`$API_KEY_ARG` is empty without a key); one `exec` now.
- **Owned runtime tree**: `chown -R user:user /opt/strata` — the built image left the venv root-owned while the runtime is uid 1000, which killed first start with `PermissionError: /opt/strata/.venv/.strata-pip.json`.
- **External model / run args**: the run-args surface (IQ3_S shard pair, PLE pack, MTP head, `--vram-reserve-mib`, `--kv`, `--spec`, `--max-context`) is exercised by the bed via `strata-gpu-run-args`; the deploy resolves `MODEL` into the per-tag config so a local model ships without an install pass.
- **Stale mock bed**: the withdrawn `check-strata-pod` references are removed from the config **and** `AGENTS.md` (the R5 sweep had missed the latter); the GPU-free mock mode is documented as a runtime posture (`STRATA_ENGINE=mock`), not a bed.
